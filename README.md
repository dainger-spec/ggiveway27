# Europe New Year Giveaway — Telegram-бот для розыгрыша

Бот: [@EuGive2027_bot](https://t.me/EuGive2027_bot). Токен и ID администратора уже прописаны в файле `.env`.

Бот показывает участникам список спонсоров (каналы, чаты, боты), проверяет подписку на каналы и вступление в чаты
и после выполнения всех условий выдаёт **уникальный порядковый номер участника** (№1, №2, №3…).

## Запуск на хостинге

Нужен **Python 3.10 или новее**.

1. Загрузите на хостинг **все файлы архива**, включая `.env`. Это скрытый файл: если его не видно в файловом
   менеджере, включите показ скрытых файлов.
2. Установите зависимости: `pip install -r requirements.txt`. Многие панели хостинга делают это сами при наличии
   `requirements.txt`.
3. Укажите **файл запуска: `main.py`** и язык **Python**. Если запускаете вручную, выполните `python3 main.py`.
4. Откройте бота в Telegram, нажмите `/start`, затем `/admin`.

Бот должен работать **в одном экземпляре**. Если запустить его одновременно в двух местах, Telegram выдаст ошибку
`Conflict: terminated by other getUpdates request`.

### Настройки (`.env`)

| Переменная      | Значение                                                                 |
|-----------------|--------------------------------------------------------------------------|
| `BOT_TOKEN`     | Токен бота от @BotFather                                                 |
| `ADMIN_IDS`     | Telegram ID администраторов через запятую. Если не задано — `1457986905` |
| `DATA_DIR`      | Папка для базы и файлов. Bothost задаёт её сам: `/app/data`              |
| `DB_PATH`       | Файл базы данных, по умолчанию `DATA_DIR/giveaway.db`                    |
| `GIVEAWAY_NAME` | Название розыгрыша, по умолчанию `Europe New Year Giveaway`              |
| `WEBAPP_URL`    | Адрес мини-приложения. По умолчанию — `DOMAIN` от Bothost или `https://giveaway.bothost.tech` |
| `PORT`          | Порт веб-сервера. Bothost передаёт его сам; без него — `8080`            |
| `MEDIA_DIR`     | Папка для фона и аватарок, по умолчанию `DATA_DIR/media`                 |
| `CAPTCHA_WORDS` | Свои слова для капчи через запятую. Если не задано — встроенный список   |

Если хостинг позволяет задавать переменные окружения в панели, можно указать их там вместо `.env`.

> ⚠️ В `.env` лежит токен бота: не публикуйте архив и этот файл. Если токен утёк, в @BotFather выполните
> `/revoke`, получите новый токен и замените его в `.env`.

## Возможности

**Для участников**
- `/start` показывает список спонсоров: кнопки-ссылки и суммы, которые выделил каждый спонсор.
- Кнопка «✅ Проверить подписку» проверяет все каналы и чаты и показывает, чего не хватает.
- Когда всё выполнено, участник получает следующий по порядку номер. Повторно номер не выдаётся.

**Админ-панель** (`/admin`)
- 📋 Спонсоры: список и карточка спонсора с проверкой, является ли бот там администратором.
- ➕ Добавление канала, чата или бота.
- 💰 Изменение или удаление суммы у спонсора. 🗑 Удаление спонсора.
- 👥 Список участников с номерами.
- 🔎 Поиск участника по номеру или @username и кнопка «🔄 Проверить подписки сейчас»: проверьте победителя перед
  выдачей приза.
- 📥 Выгрузка участников в CSV (открывается в Excel и Google Таблицах).
- 📣 Рассылка о новых спонсорах: всем пользователям бота приходит, что нужно сделать — подписаться на канал,
  вступить в чат или запустить бота, — с кнопками-ссылками.

## Мини-приложение

Внутри бота открывается красивое приложение:

1. **Приветствие:** имя участника, общий призовой фонд в кольце из звёзд ЕС, число спонсоров и участников,
   кнопка «Участвовать».
2. **Спонсоры:** каждый спонсор — капсула с аватаркой, суммой и кнопкой «Подписаться» / «Вступить» / «Запустить».
   Кнопка открывает канал прямо в Telegram. Когда участник возвращается в приложение, подписка проверяется,
   и капсула загорается зелёным.
3. **Номер:** когда всё выполнено, кнопка «Получить номер» выдаёт номер (тот же счётчик, что и в боте),
   а бот дублирует его в чат.

Общий призовой фонд считается автоматически из сумм спонсоров. Разные валюты складываются отдельно:
`2 150 $ + 100 USDT`.

**Фон:** `/admin` → «⚙️ Настройки приложения» → «📤 Загрузить фон» → пришлите картинку, GIF или видео (до 20 МБ). Фон растягивается
на весь экран и слегка затемняется. Чтобы Telegram не сжимал картинку, отправляйте её как файл.

**Аватарка спонсора:** `/admin` → «📋 Спонсоры» → спонсор → «🖼 Аватарка» → пришлите картинку (лучше квадратную).
Она заменяет фото канала в кружке слева в капсуле, а у ботов — первую букву названия. Убрать — «🚫 Убрать аватарку».

**Фон капсулы спонсора:** `/admin` → «📋 Спонсоры» → спонсор → «🌄 Фон капсулы» → пришлите картинку, GIF
или видео. Фон показывается внутри капсулы этого спонсора и затемняется слева, чтобы название и сумма
читались. После подписки капсула всё равно загорается зелёным. Убрать — «🚫 Убрать фон».

### Капча перед выдачей номера

Когда все условия выполнены, перед номером участник пишет **слово с картинки**. Слова — из тематики
(кардинг, прокси, антик, ролка, дроп, логи, чекер…). Картинка каждый раз рисуется заново:

- каждая буква — своим шрифтом, цветом, размером и под своим углом, буквы немного наезжают друг на друга;
- слово изогнуто волной, через него проходят линии того же цвета, что и буквы;
- по фону рассыпаны бледные случайные буквы, чтобы программе было сложнее найти, где слово.

Человек читает слово сразу, а распознать его ботом заметно сложнее, чем ровные цифры. Ответ знает только
сервер. Большие и маленькие буквы, пробелы и «ё»/«е» не важны; слово, набранное в английской раскладке
(«hjkrf»), тоже засчитывается.

- **В мини-приложении** слово вводят в поле под картинкой и нажимают «Готово».
- **В чате с ботом** (если условия проверяли кнопкой «✅ Проверить подписку») бот присылает картинку, а слово
  нужно отправить обычным сообщением. Под картинкой есть кнопка «🔄 Другое слово».

Ошибся — сразу приходит новое слово. Капча одноразовая: не больше 8 картинок за 10 минут на человека, поэтому
подбирать слова перебором долго. Список слов лежит в открытом репозитории — чтобы его не знали заранее,
задайте свой в переменной `CAPTCHA_WORDS` на хостинге (через запятую, 3–12 букв). Выключить капчу: `/admin` →
«⚙️ Настройки приложения».

### Как подключить на Bothost

Адрес `https://giveaway.bothost.tech` уже прописан в коде, переменные задавать не нужно.

1. В настройках бота на Bothost включите **«Использовать домен»**.
2. Поле **«Порт»** оставьте как есть: Bothost передаёт его боту в переменной `PORT`, и бот слушает именно его
   (на `0.0.0.0`, как требует Bothost).
3. Пересоберите бота. Слева от поля ввода появится кнопка «🎁 Гив», а в `/start` — «🎁 Открыть приложение».

Если в логах ошибка `ReferenceError: window is not defined` или бот запускается через `node`, хостинг
ошибся с языком. В «Дополнительных настройках» укажите **«Главный файл (точка входа)»: `main.py`** и сделайте
новый деплой. Самый надёжный вариант — включить **«Использовать собственный Dockerfile»**: в репозитории лежит
`Dockerfile`, который всегда запускает `python main.py`.

Проверка: откройте `https://giveaway.bothost.tech/health` — должно показать `ok`. Если видите
`404 page not found` или `502`, значит домен не включён или бот ещё не пересобран.

На другом хостинге укажите свой адрес в `WEBAPP_URL` и откройте для бота порт из `PORT`.

Боты-спонсоры в приложении засчитываются после нажатия «Запустить»: Telegram не позволяет проверить запуск
чужого бота. Номер выдаётся только после настоящей проверки всех каналов и чатов.

## Как добавить спонсора

1. **Добавьте @EuGive2027_bot администратором** в канал или чат спонсора. Без этого Telegram не даёт боту
   проверять подписчиков. Право «Пригласительные ссылки» нужно, только если бот должен сам создать ссылку
   на приватный канал.
2. В боте: `/admin` → «➕ Добавить спонсора» и пришлите **что угодно из этого** — бот сам поймёт,
   канал это, чат или бот:
   - ссылку `https://t.me/channel`, `t.me/s/channel`, ссылку на любой пост или просто `@channel`;
   - ссылку-приглашение в приватный канал или чат: `https://t.me/+AbCd…` или `t.me/joinchat/…`;
   - ссылку на пост приватного канала `https://t.me/c/…`, ID `-100…` или пересланный пост;
   - бота: `@some_bot` или реферальную ссылку `https://t.me/some_bot?start=ref`;
   - или выберите кнопкой «📢 Выбрать канал», «💬 Выбрать чат», «🤖 Выбрать бота».
3. Укажите сумму (`500$`, `100 USDT`, …) или нажмите «Пропустить». Сумму можно поменять в любой момент.

**Приватные каналы.** По ссылке-приглашению Telegram не говорит боту, что это за канал. Бот запоминает все
каналы и чаты, куда его назначили администратором, и сам находит нужный по основной ссылке-приглашению.
Если ссылка дополнительная (созданная вручную), бот покажет список каналов, где он админ, — достаточно
нажать нужный. Ссылка, которую вы прислали, останется ссылкой для участников.

Каналы, куда бота назначили админом до этого обновления, бот ещё не знает. Для них один раз перешлите
боту пост из канала или выберите его кнопкой «📢 Выбрать канал».

**Каналы и чаты по заявкам.** Пока заявку не одобрили, Telegram считает человека не вступившим. Поэтому бот
сам запоминает поданные заявки и засчитывает их как выполненное условие (одобрять заявку или нет — решает
спонсор). Для этого у бота в канале/чате должно быть право **«Добавление участников»** (пригласительные
ссылки) — без него Telegram не сообщает боту о заявках. Есть ли это право, видно в карточке спонсора.
Заявки, поданные до этого обновления, бот не видел: таким участникам нужно, чтобы заявку одобрили.

**Боты-спонсоры.** Telegram не позволяет проверить, запускал ли пользователь чужого бота. Поэтому боты
показываются участникам как условие, но автоматически не проверяются. Каналы и чаты проверяются всегда.

## Рассылка о новых спонсорах

Когда вы добавляете спонсора, бот сам предлагает сообщить о нём пользователям: показывает, сколько человек
получат сообщение, и кнопки «📣 Разослать», «👀 Как это увидят» и «Позже». Если добавляете сразу несколько
спонсоров, можно нажать «Позже» и разослать обо всех одним сообщением: `/admin` → «📣 Рассылка о новых
спонсорах».

- Получают все, кто запускал бота или открывал мини-приложение, кроме заблокировавших бота.
- В сообщении — что сделать у каждого нового спонсора: «Подпишись на канал», «Вступи в чат», «Запусти бота», —
  кнопки-ссылки, кнопка приложения и «✅ Проверить подписку».
- Участникам с номером бот напоминает, что номер сохраняется. Если они нажмут «Проверить подписку», бот
  покажет, на каких новых спонсоров они ещё не подписаны.
- Рассылка идёт в фоне, около 25 сообщений в секунду (лимит Telegram — 30). Прогресс обновляется в сообщении
  у админа, её можно остановить кнопкой «⏹ Остановить рассылку». В конце бот пишет, сколько доставлено и
  сколько людей заблокировали бота.
- Обо всех спонсорах, добавленных до этого обновления, бот считает, что уже сообщил. Если ботом ещё никто,
  кроме админов, не пользовался, рассылку не предлагает.

## Нумерация и данные

- Номера идут строго по порядку без пропусков и повторов, даже если много людей нажимают кнопку одновременно.
- Один Telegram-аккаунт получает только один номер.
- Все данные лежат в папке `data`: база `giveaway.db`, фон и аватарки в `media`. На Bothost это `/app/data` —
  единственная папка, которая сохраняется при обновлении из GitHub. Для бэкапа скачайте её через файловый
  менеджер панели. Если база раньше лежала в корне проекта, бот сам перенесёт её в `data` при запуске.

## Запуск на своём VPS (systemd)

```bash
cd /opt/europe-giveaway-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

`/etc/systemd/system/giveaway-bot.service`:

```ini
[Unit]
Description=Europe Private Giveaway bot
After=network-online.target

[Service]
WorkingDirectory=/opt/europe-giveaway-bot
ExecStart=/opt/europe-giveaway-bot/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now giveaway-bot
journalctl -u giveaway-bot -f     # логи
```
