# Europe Private Giveaway — Telegram-бот для розыгрыша

Бот: [@EuGive2027_bot](https://t.me/EuGive2027_bot). Токен и ID администратора уже прописаны в файле `.env`.

Бот показывает участникам список спонсоров (каналы, чаты, боты), проверяет подписку на каналы и вступление в чаты
и после выполнения всех условий выдаёт **уникальный порядковый номер участника** (№1, №2, №3…).

## Запуск на хостинге

Нужен **Python 3.10 или новее**.

1. Загрузите на хостинг **все файлы архива**, включая `.env`. Это скрытый файл: если его не видно в файловом
   менеджере, включите показ скрытых файлов.
2. Установите зависимости: `pip install -r requirements.txt`. Многие панели хостинга делают это сами при наличии
   `requirements.txt`.
3. Укажите **файл запуска: `main.py`**. Если запускаете вручную, выполните `python3 main.py`.
4. Откройте бота в Telegram, нажмите `/start`, затем `/admin`.

Бот должен работать **в одном экземпляре**. Если запустить его одновременно в двух местах, Telegram выдаст ошибку
`Conflict: terminated by other getUpdates request`.

### Настройки (`.env`)

| Переменная      | Значение                                                                 |
|-----------------|--------------------------------------------------------------------------|
| `BOT_TOKEN`     | Токен бота от @BotFather                                                 |
| `ADMIN_IDS`     | Telegram ID администраторов через запятую, например `1457986905,123456`  |
| `DB_PATH`       | Файл базы данных, по умолчанию `giveaway.db` рядом с `main.py`           |
| `GIVEAWAY_NAME` | Название розыгрыша                                                       |

Если хостинг позволяет задавать переменные окружения в панели, можно указать их там вместо `.env`.

> ⚠️ В `.env` лежит токен бота: не публикуйте архив и этот файл. Если токен утёк, в @BotFather выполните
> `/revoke`, получите новый токен и замените его в `.env`.

## Возможности

**Для участников**
- `/start` показывает список спонсоров: кнопки-ссылки и суммы, которые выделил каждый спонсор.
- Кнопка «✅ Проверить подписку» проверяет все каналы и чаты и показывает, чего не хватает.
- Когда всё выполнено, участник получает следующий по порядку номер. Повторно номер не выдаётся.

**Админ-панель** (`/admin`)
- 📋 Спонсоры: список и карточка спонсора с проверкой, является ли бот там администратором.
- ➕ Добавление канала, чата или бота.
- 💰 Изменение или удаление суммы у спонсора. 🗑 Удаление спонсора.
- 👥 Список участников с номерами.
- 🔎 Поиск участника по номеру или @username и кнопка «🔄 Проверить подписки сейчас»: проверьте победителя перед
  выдачей приза.
- 📥 Выгрузка участников в CSV (открывается в Excel и Google Таблицах).

## Как добавить спонсора

1. **Добавьте @EuGive2027_bot администратором** в канал или чат спонсора. Без этого Telegram не даёт боту
   проверять подписчиков. Право «Пригласительные ссылки» нужно, только если бот должен сам создать ссылку
   на приватный канал.
2. В боте: `/admin` → «➕ Добавить спонсора» → Канал или Чат.
3. Выберите канал кнопкой «📢 Выбрать канал», либо пришлите `@username`, ссылку, ID `-100…` или перешлите пост из канала.
4. Подтвердите ссылку для участников или пришлите свою.
5. Укажите сумму (`500$`, `100 USDT`, …) или нажмите «Пропустить». Сумму можно поменять в любой момент.

**Боты-спонсоры** добавляются по `@username` или ссылке, в том числе реферальной (`https://t.me/some_bot?start=ref`).
Telegram не позволяет проверить, запускал ли пользователь чужого бота. Поэтому боты показываются участникам как
условие, но автоматически не проверяются. Каналы и чаты проверяются всегда.

## Нумерация и данные

- Номера идут строго по порядку без пропусков и повторов, даже если много людей нажимают кнопку одновременно.
- Один Telegram-аккаунт получает только один номер.
- Все данные хранятся в файле `giveaway.db`. Для бэкапа скопируйте его. **Не удаляйте этот файл при обновлении
  бота**, иначе пропадут участники и спонсоры.

## Запуск на своём VPS (systemd)

```bash
cd /opt/europe-giveaway-bot
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
```

`/etc/systemd/system/giveaway-bot.service`:

```ini
[Unit]
Description=Europe Private Giveaway bot
After=network-online.target

[Service]
WorkingDirectory=/opt/europe-giveaway-bot
ExecStart=/opt/europe-giveaway-bot/.venv/bin/python main.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now giveaway-bot
journalctl -u giveaway-bot -f     # логи
```

## Структура

```
main.py                     — файл запуска
.env                        — токен, ID админов, настройки
requirements.txt            — зависимости
giveaway/config.py          — чтение настроек
giveaway/database.py        — SQLite: спонсоры, участники, выдача номеров
giveaway/checker.py         — проверка подписок через Telegram API
giveaway/commands.py        — меню команд бота
giveaway/texts.py           — тексты сообщений
giveaway/keyboards.py       — кнопки
giveaway/handlers/user.py   — участники: /start и проверка подписки
giveaway/handlers/admin.py  — админ-панель
```
